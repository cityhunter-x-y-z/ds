🐛 Debug: Toggle State Issues

❌ Issue Identified

Problem: On mouse click, only focus ring appears but toggle state doesn't change to 'on'

Root Cause Analysis:

// WRONG: Controlled/Uncontrolled detection const currentToggle = onChange ? toggle : internalToggle; // This means if onChange exists, it uses the prop value // But the prop might be undefined, so it stays undefined!

✅ Fix Applied

Solution: Proper controlled/uncontrolled detection based on prop presence

Fixed Logic:

// CORRECT: Check if toggle prop is explicitly provided const isControlled = toggle !== undefined; const currentToggle = isControlled ? toggle : internalToggle; // This properly handles: // 1. Uncontrolled: No toggle prop → uses internal state // 2. Controlled: toggle prop provided → uses prop value
