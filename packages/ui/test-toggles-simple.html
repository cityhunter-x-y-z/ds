📝 Implementation Details

Uncontrolled Mode (Default)

When no onChange prop is provided, components manage their own state:

// Internal state for uncontrolled mode const [internalToggle, setInternalToggle] = useState(toggle); // Use controlled or uncontrolled value const currentToggle = onChange ? toggle : internalToggle;

Controlled Mode

When onChange is provided, components use the toggle prop:

// Update internal state if uncontrolled if (!onChange) { setInternalToggle(newChecked ? 'on' : 'off'); } // Call onChange if provided onChange?.(newChecked, event);
